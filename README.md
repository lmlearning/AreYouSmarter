# Are You Smarter?

An interactive quiz application for exploring how human answers compare with AI benchmark performance.

The project includes a React/TypeScript interface, quiz questions, AI model comparisons and a results dashboard.

## Start here

See [SETUP.md](SETUP.md) for installation, local development, data preparation and optional database configuration.

## Explore the implementation

- [client/src](client/src/): application interface and components.
- [server](server/): backend implementation.
- [package.json](package.json): dependencies and available commands.

Benchmark comparisons reflect the datasets and model figures supplied to the application; a quiz result is not a general measure of human or AI intelligence.
